# Action Band（実行バンドプロジェクト）

「今までやろうやろうと言ってたけどやってなかったこと」をやってみよう。
実行バンドのインセンティブを得て、一歩を踏み出すきっかけに。

## 主な機能

- **目標の宣言** — 実行したいことを決めて、バンドに込めて宣言する
- **取り組み一覧** — 他のみんなの挑戦を見て、刺激をもらう
- **日記・記録** — 日々の取り組みを記録して振り返る
- **達成報告** — 目標を達成したら次の人にバトンを渡す

## プロジェクトの進め方

1. 友達などから実行バンドを引き継ぐ
2. 目標を決めて宣言する
3. 目標達成に向けて行動し、日記を書く
4. 達成したら次の人にバトンを渡す

## 開発技術

- **Frontend**: React + TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## ローカルでの動かし方

```bash
npm install
npm run dev
```
